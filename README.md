# ممالك — لعبة بناء واستكشاف استراتيجية

مشروع لعبة ثلاثية الأبعاد مبني باستخدام HTML وThree.js، بفكرة بناء مملكة وتطوير مدينة واستكشاف العالم.

## الموجود حالياً
- واجهة عربية متجاوبة مع شاشات الهاتف.
- مشهد ثلاثي الأبعاد مع كاميرا قابلة للدوران والتقريب.
- موارد أولية وأزرار البناء والاستكشاف.
- حفظ محلي لمواضع المباني.
- فهرس أصول `assets-manifest.json`.

## الأصول ثلاثية الأبعاد
حزمة المصدر الأصلية تحتوي على 107 ملفات FBX. لم تُرفع ملفات FBX إلى المستودع بعد، لذلك لا تعتبر النماذج الأصلية مدمجة أو جاهزة للتحميل في النسخة المنشورة. يجب رفع الملفات مع الحفاظ على مساراتها ثم تعبئة `assets-manifest.json` بمساراتها الصحيحة.

## التشغيل
يجب تشغيل المشروع عبر خادم HTTP أو استضافة صفحات ثابتة، وليس بفتح `index.html` مباشرة. يعتمد المشروع على Three.js من CDN.

## النشر عبر GitHub Pages
أُضيف سير عمل GitHub Actions في `.github/workflows/deploy-pages.yml` للنشر التلقائي عند كل تحديث لفرع `main`. لتفعيله أول مرة:
1. افتح إعدادات المستودع في GitHub.
2. اختر **Pages**.
3. في **Build and deployment** اختر **GitHub Actions** كمصدر.
4. انتظر اكتمال سير عمل **Deploy Mamalik Kingdom to GitHub Pages** من تبويب Actions.

## حدود النسخة
هذه نسخة تأسيسية وليست لعبة مكتملة. أنظمة السكان والاقتصاد والمهام والتقدم غير مكتملة، ويجب اختبار التشغيل على متصفح Android بعد النشر. لا يوجد حتى الآن اختبار تشغيل فعلي على الهاتف.
