# ممالك — لعبة بناء واستكشاف استراتيجية

مشروع لعبة ثلاثية الأبعاد مبني باستخدام HTML وThree.js، بفكرة بناء مملكة وتطوير مدينة واستكشاف العالم.

## نطاق النسخة الأولية
- مشهد ثلاثي الأبعاد قابل للدوران والتقريب.
- كتالوج مبانٍ وموارد من ملفات FBX.
- وضع بناء مع معاينة قبل تثبيت المجسم.
- حفظ مواقع المباني محلياً في المتصفح.
- واجهة عربية متوافقة مع شاشات الهاتف.

## التشغيل
يجب تشغيل المشروع عبر خادم HTTP أو استضافة صفحات ثابتة، وليس بفتح `index.html` مباشرة.
بعد اكتمال رفع ملفات المشروع والأصول، يمكن تشغيله عبر أي استضافة Static Site تدعم ملفات JavaScript وJSON وFBX.

## حالة التطوير
هذه نسخة تأسيسية قيد التطوير. لا تعتبر أنظمة الاقتصاد أو المهام أو الاستكشاف المتقدم مكتملة بعد. كما يجب اختبار تشغيل اللعبة فعلياً على متصفح Android بعد نشر الملفات.

## الأصول
مصدر المشروع يتضمن حزمة نماذج FBX. يجري تنظيم ورفع النماذج إلى المستودع مع الحفاظ على مسارات الملفات المشار إليها في `assets-manifest.json`.
